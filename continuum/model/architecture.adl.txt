    capability InvestigateData
      requirement BoundedExecution — "Every query runs within configured timeout, row, byte, concurrency and per-investigation query budgets, can be cancelled, and reports when its result was truncated."
      requirement EvidenceProvenance — "Every executed query carries a query id, the exact SQL, the connection alias and timestamps; investigations persist questions, hypotheses, findings and uncertainty without raw result rows by default."
      requirement LocalOnlyProvisioning — "Connections and their credentials are provisioned only through a local interactive command run by the developer; no MCP operation accepts or returns a credential."
      requirement NoSecretDisclosure — "Credentials and connection secrets never appear in MCP output, diagnostics, investigation history or the knowledge store."
      requirement ReadOnly — "Only bounded, authorized read-only SQL queries may execute. The gateway accepts exactly one bounded SELECT per request, referencing only objects and columns within the alias's approved scope, through a fail-closed allowlist, and a dedicated read-only SQL principal denies writes independently of that validation."
      requirement ReviewedRelationships — "Inferred cross-database relationships stay proposed, with provenance, until explicitly reviewed; rejected relationships and their evidence are retained and never promoted."
      requirement SafeFailure — "SQL errors, cancellation, schema drift and unreachable databases produce actionable, sanitized errors and never fabricated results."
      requirement SchemaFreshness — "Schema snapshots record their source and capture time and are refreshed when drift is detected."
      requirement SeparatePerDatabaseQueries — "Each query targets exactly one connection alias. Cross-database correlation happens on the agent side over separate bounded results, never in cross-database or linked-server SQL."
      requirement SoleConversationalHost — "Claude Code is the only conversational interface. The server speaks MCP over stdio, keeps stdout for protocol messages only, and offers no other chat, web or model surface."
    policy ProductionDataApproval — "No production data reaches Claude Code until the data owner has approved the specific data classifications and environment."
