# ADR-005: Separate queries and agent-side correlation

Status: **Candidate — agreed in conversation; not yet recorded or accepted in the governed Continuum ledger.**

## Decision
Query each authorized database independently; Claude Code correlates bounded observations and reports ambiguous matches.

## Alternatives and rationale
Linked servers and cross-database server-side joins broaden privileges and create hidden coupling.

## Consequences
Preserve provenance and avoid asserting unverified relationships.

## Governance
Requires proposal and authorized acceptance in a dedicated SQL Investigator decision space; no Host event or actor is claimed.
