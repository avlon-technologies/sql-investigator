# ADR-004: Local JSON and DPAPI, not SQLite

Status: **Proposed** in the Host-governed SQL Investigator decision space (proposal event 5, check event 11). **Not accepted.** Read the live status with `continuum decision show ADR-004`; this file is a readable copy, never the record.

## Decision
Use System.Text.Json with atomic writes for metadata, knowledge and history; encrypt credentials separately with Windows DPAPI CurrentUser.

## Alternatives and rationale
SQLite adds a database dependency unnecessary for single-user local use; plaintext credentials are unacceptable.

## Consequences
Use single-writer discipline, restrictive ACLs, recovery tests and secret-redacted logs.
