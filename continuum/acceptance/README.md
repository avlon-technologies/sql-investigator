# Acceptance — sql-investigator

> Generated by `tools/development-package.mjs`. Executable specification: the scenarios are data, the runner is shipped, the adapter is yours. Every scenario is traceable to the semantic model (validated at package build: an unresolvable reference fails the build).

## Run

```
node acceptance/run.mjs --check                              # shape only
node acceptance/run.mjs --adapter acceptance/adapter.mjs     # execute (default adapter path)
node acceptance/run.mjs --only <scenario-name> --json
```

This model declares no Agent: no model provider takes part, `MODEL_PROVIDER` is irrelevant, and no scenario needs an API key. The shipped `fake-model-provider.mjs` is the runner's fixed companion and is unused here.
