# ADR-006: Continuum at design time, optional knowledge at runtime

Status: **Candidate — agreed in conversation; not yet recorded or accepted in the governed Continuum ledger.**

## Decision
Use Continuum for architecture governance and implementation handoff; allow optional exported context files but no Continuum runtime dependency.

## Alternatives and rationale
A runtime dependency would complicate a small local investigation tool.

## Consequences
The executable works offline from Continuum; imported architecture knowledge is tagged with source and freshness.

## Governance
Requires proposal and authorized acceptance in a dedicated SQL Investigator decision space; no Host event or actor is claimed.
