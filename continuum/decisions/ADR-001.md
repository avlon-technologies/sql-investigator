# ADR-001: Claude Code as sole agent host

Status: **Candidate — agreed in conversation; not yet recorded or accepted in the governed Continuum ledger.**

## Decision
Use Claude Code as the only conversational agent; host a local .NET MCP stdio process; no separate web UI or local model.

## Alternatives and rationale
A standalone chat application, web service, or embedded LLM adds operational and security surfaces.

## Consequences
The developer interacts through Claude Code; MCP tools must remain model-agnostic at the transport level without introducing a second agent host.

## Governance
Requires proposal and authorized acceptance in a dedicated SQL Investigator decision space; no Host event or actor is claimed.
