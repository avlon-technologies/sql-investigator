# ADR-002: SQL Server and T-SQL only

Status: **Proposed** in the Host-governed SQL Investigator decision space (proposal event 3, check event 9). **Not accepted.** Read the live status with `continuum decision show ADR-002`; this file is a readable copy, never the record.

## Decision
Support SQL Server and T-SQL, using Microsoft.Data.SqlClient and ScriptDom.

## Alternatives and rationale
Generic database provider abstraction would dilute grammar-specific safety guarantees.

## Consequences
SQL dialect and SQL Server permissions can be tested precisely; other engines are out of scope.
