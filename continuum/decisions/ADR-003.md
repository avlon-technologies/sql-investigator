# ADR-003: Bounded autonomous read-only investigation

Status: **Accepted** in the Host-governed SQL Investigator decision space (proposal event 4, check event 10, acceptance event 20). Accepted by `agent:remote-mcp` under the Host-authorized `chatgpt-delegate` grant. Read the live status with `continuum decision show ADR-003`; this file is a readable copy, never the record.

## Decision
Allow Claude Code to run multiple SELECT investigations without per-query approval only within independent, fail-closed MCP and SQL Server policy boundaries.

## Alternatives and rationale
Per-SELECT human approval harms the intended workflow; trusting the model to self-police is unsafe.

## Consequences
Reject unsupported AST forms, writes, multi-batches, unsafe references and excessive work; use read-only principals and evidence logs.
